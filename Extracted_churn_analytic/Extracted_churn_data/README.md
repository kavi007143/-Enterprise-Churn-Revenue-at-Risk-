# Customer Behavior & Churn Prediction Dataset V2

## Overview

The Customer Behavior & Churn Prediction Dataset V2 is a large-scale synthetic relational dataset designed for machine learning, data analytics, SQL practice, business intelligence, and customer churn prediction.

This version significantly expands the original dataset by introducing multiple interconnected tables, richer customer behavior, realistic business relationships, and advanced customer analytics features.

The dataset is entirely synthetic and intended for educational purposes, portfolio projects, research, and experimentation.
